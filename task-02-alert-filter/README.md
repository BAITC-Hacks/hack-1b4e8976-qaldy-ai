# Фильтр алертов

Небольшой Python-скрипт читает восемь событий из файла `events.json`
и отфильтровывает информационный шум. В консоль попадают только события
с уровнем `critical`, после чего выводится итоговая строка с их количеством.

## Состав проекта

- `events.json` — восемь исходных событий с уровнями `info`, `warn`
  и `critical`;
- `alert_filter.py` — фильтр критичных событий.

## Как запустить

Требуется Python 3. Дополнительные библиотеки, интернет и API-ключи
не нужны.

Откройте терминал в папке `task-02-alert-filter` и выполните:

```bash
python alert_filter.py
```

В Windows также можно использовать:

```bash
py alert_filter.py
```

## Результат

Скрипт выводит три критичных события:

```text
critical: disk 90%
critical: payment failed
critical: db timeout
критичных 3
```

События уровней `info` и `warn` в вывод не попадают.
