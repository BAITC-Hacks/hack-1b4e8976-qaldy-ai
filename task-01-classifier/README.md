# Классификатор обращений

Небольшой Python-скрипт читает пять обращений из файла `messages.txt`,
определяет категорию каждого обращения и формирует черновик ответа
на русском языке.

Используются три категории:

- справка;
- жалоба;
- другое.

## Как запустить

Требуется Python 3.

Откройте терминал в папке проекта и выполните:

```bash
python classifier.py
```

В Windows также можно использовать:

```bash
py classifier.py
```

## Результат

Для каждого обращения программа выводит:

1. исходный текст;
2. категорию;
3. черновик ответа.

Классификация выполняется по ключевым словам, поэтому интернет,
API-ключи и установка дополнительных библиотек не требуются.
