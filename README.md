# Репетиционные задания QALDY AI

В репозитории собраны небольшие решения на Python без внешних библиотек,
API и платных сервисов.

## Задания

1. [Классификатор обращений](task-01-classifier/README.md) — определяет
   категорию обращения и предлагает черновик ответа.
2. [Фильтр алертов](task-02-alert-filter/README.md) — оставляет только
   критичные события и выводит их количество.
