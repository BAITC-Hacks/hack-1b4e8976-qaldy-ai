# Есть дефект или нет

Небольшой скрипт на Python принимает одно изображение и определяет,
является ли оно нормой или дефектом. Готовая модель, нейросеть, интернет
и внешние API не используются: решение основано на простом анализе цвета.

В проекте есть два контрольных изображения:

- `ok.png` — зелёный квадрат без дефекта;
- `defect.png` — красный квадрат с дефектом.

## Как работает классификация

Скрипт переводит изображение в RGB и считает долю красных пикселей.
Пиксель считается красным, если его красный канал не меньше 180 и
превышает зелёный и синий каналы как минимум на 50. Если таких пикселей
30% или больше, результат — `DEFECT`; в остальных случаях — `OK`.

## Установка

Требуется Python 3. Откройте терминал в папке проекта и установите Pillow:

```bash
python -m pip install -r requirements.txt
```

## Запуск

Передайте скрипту путь к одному изображению:

```bash
python detector.py ok.png
python detector.py defect.png
```

Полученный результат:

```text
OK
DEFECT
```

## Проверка

Автоматические тесты запускаются командой:

```bash
python -m unittest -v test_detector.py
```

Тесты подтверждают, что `ok.png` классифицируется как `OK`, а
`defect.png` — как `DEFECT`.
